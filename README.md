# Cybersecurity Awareness Notes and Guide 
## About the Project
Cybersecurity awareness means educating people about the cyberthreats, risks and cybersecurity practices that help protect organisation, computers, systems and individuals from cyberattacks. This project provides notes and simple steps that individuals can use to protect themselves from such attacks.
